# HairFlow 美髮會員系統

這是一個可直接開啟使用的前端單頁系統，提供美髮沙龍常見的會員與營運管理功能。

## 功能

- 會員管理（新增姓名、手機、生日、等級）
- 服務與套票管理（價格、時長）
- 預約排程（會員、服務、設計師、日期時間）
- 消費交易與點數累積（每 20 元累 1 點）
- 會員儲值金扣款邏輯
- 庫存安全量提醒
- 生日/預約/回訪訊息範本
- 儀表板 KPI（會員、營收、今日預約、總點數）
- 月營收趨勢圖（近 6 個月）
- LocalStorage 資料持久化與一鍵重設示範資料

## 使用方式

直接在瀏覽器開啟 `index.html` 即可，或使用簡單靜態伺服器：

```bash
python3 -m http.server 8000
```

開啟：<http://localhost:8000>
